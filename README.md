# Hospital-Emergency-Room-Dashboard
Interactive Power BI dashboard for hospital emergency room analytics and patient insights.

🏥 Hospital ER Dashboard (Power BI)

📌 Overview
This project is an interactive Hospital Emergency Room (ER) dashboard built using Microsoft Power BI. It analyzes patient flow, waiting time, admission status, and satisfaction levels to generate meaningful healthcare insights.

🎯 Objective

The goal of this project is to analyze ER operations and provide insights on:

Patient arrival trends
Average waiting time
Admission vs non-admission cases
Patient satisfaction levels
Peak traffic hours in ER

🛠 Tools Used
Microsoft Power BI
Power Query (Data Cleaning & Transformation)
DAX (Data Analysis Expressions)
Excel (Dataset Source)

📊 Key Features
KPI cards for key metrics (Total Patients, Avg Wait Time, Satisfaction Score)
Admission status analysis
Time-based trend visualization
Interactive slicers and filters
Clean and user-friendly dashboard design

📈 Key Insights
ER experiences higher patient inflow during peak hours
Majority of patients are not admitted
Waiting time varies based on patient load
Patient satisfaction remains moderate with scope for improvement

🚀 How to Use
Open the .pbix file using Microsoft Power BI Desktop and explore the interactive dashboard using filters and visuals.
